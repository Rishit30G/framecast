# Security

Framecast records screens and microphones, so security reports are taken seriously.

**Please don't report a vulnerability in a public issue.** Use GitHub's [private vulnerability reporting](https://github.com/Rishit30G/framecast/security/advisories/new) instead, with steps to reproduce and the version you tested.

You'll get a reply as soon as possible, and a fix will be released before any details are made public.

Framecast doesn't send recordings anywhere. Recording, transcription, voice clean-up and export all run on your Mac. If you find a case where data leaves the machine unexpectedly, that's a security bug.
